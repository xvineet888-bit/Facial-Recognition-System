Evaluation methodology

The Labeled Faces in the Wild (LFW) dataset is divided into a gallery and a separate test set. Each test face is compared with the gallery, and the closest identity is accepted only when its distance is within the configured threshold. This evaluation uses a separate research dataset and does not modify registered users in the website database.

Interpretation

Known-person rejections occur when a genuine gallery identity is not accepted. Misidentifications occur when a test face is accepted but assigned to the wrong gallery identity. False acceptances occur when an identity absent from the gallery is incorrectly matched to a gallery identity. These measures describe different aspects of recognition performance.
